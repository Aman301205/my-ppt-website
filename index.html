  • **Personalization** directly correlates to User Retention

The Problem

  • Excessive **content choices** causing paralysis
  • Lack of **deep personalization** in existing tools

Speaker Notes: - Specifically, the problems are: Too much choice, Lack of true personalization, and Wasted time. - We need to move away from generic "Top 10" lists to tailored experiences.

Our Solution

  • **Personalized suggestions** analyzing specific metadata
  • **Real-time improvement** based on continuous user input
  • A **seamless, immersive UI/UX** experience

System Types

  • **Content-Based Filtering:** "**You liked X, here is more of X**" (Our Focus)
  • **Collaborative Filtering:** "**Users like you also liked Y**"
  • **Hybrid Approaches:** **Combining both** for maximum accuracy

***This app utilizes Content-Based Filtering via Cosine Similarity***

Speaker Notes: - Explain the three main types. - We are focusing on Content-Based to resolve the "**Cold Start**" problem for new users who haven't rated many movies yet.

  • **ML Core:** Python, Scikit-Learn

The Dataset

  • **Features:** Genres, Keywords, Cast, Director, Overview

  • **Feature Engineering:** Combining Cast, Director, and Genres into "**Tags**"
Speaker Notes: - Data is the fuel for our ML engine. We use TMDB for its rich content details. - Crucial Step: Feature Engineering—we merge all text fields into a single 'soup' to accurately capture the movie's identity.

The ML Model

  • **Vectorization:** Bag of Words (CountVectorizer)
  • **Dimension Reduction:** Stop-word removal (e.g., 'the', 'a')
  • **Metric:** Cosine Similarity (measuring angle, not distance)
  • **Logic:** Calculating the angular proximity between movie vectors
Speaker Notes: - We convert textual tags into numbers using CountVectorizer. - **Cosine Similarity** is preferred because in high-dimensional space, the angle between vectors is a better measure of similarity than the straight-line distance.
